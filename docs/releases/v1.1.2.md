# DroidPilot v1.1.2

- 升级内置 scrcpy server 至 4.1，适配新版视频协议。
- 修复旋转或画面尺寸变化后的触控坐标失配，以及边缘坐标越界。
- 新增手机与电脑之间的文本剪贴板同步，支持中文、表情及多行文本。
- 手机复制文本后自动同步到电脑；在投屏页使用 Ctrl+C/X/V 复制、剪切和粘贴。
- 多设备连接时，仅当前选中设备更新电脑剪贴板。
- 修复 Windows 剪贴板文本编码及额外换行问题。

## 下载

- `*-setup.exe`：Windows x64 安装包。
- `*_portable.exe`：Windows x64 绿色版，需要系统具备 WebView2 Runtime。
- `SHA256SUMS.txt`：下载文件校验值。

剪贴板同步仅支持文本。高版本 Android 的控制兼容性尚未完成实机验证。
