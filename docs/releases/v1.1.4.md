# DroidPilot v1.1.4

- 新增 macOS Apple 芯片（M 系列 / arm64）安装包和在线更新。
- Windows x64 文本剪贴板改为原生接口，解决复制粘贴时弹出命令行窗口及 PowerShell 启动延迟。
- 剪贴板读写移到后台，避免阻塞界面。
- 修复 macOS UTF-8 文本处理及 Linux 换行、X11 文本格式和后台剪贴板进程等待问题。

## 下载

- `*_aarch64.dmg`：macOS Apple 芯片版本，将应用拖到 Applications 后运行。
- `*-setup.exe`：Windows x64 安装包。
- `*_portable.exe`：Windows x64 绿色版，需要 WebView2 Runtime。
- `*.app.tar.gz`、`*.sig`、`latest.json`：在线更新文件。
- `SHA256SUMS.txt`：文件校验值。

macOS 使用 ad-hoc 签名，尚未经过 Apple Developer ID 签名和公证，首次打开可能受到系统安全检查限制。
本次未提供 Intel Mac 或 Linux 安装包。设备投屏与复制粘贴仍需在实际设备环境验证。
v1.1.3 Windows 安装版可在关于页检查更新；更早版本需手动安装。
