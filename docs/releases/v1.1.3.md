# DroidPilot v1.1.3

- 关于页新增在线更新，使用 GitHub Release 稳定版本作为更新源。
- 支持查看更新说明、下载进度、网络错误重试和安装更新。
- 安装前验证更新包签名，切换设置页面不会丢失下载状态。
- 重新整理关于页的版本信息、项目链接、隐私说明与开源许可，适配中英文和深浅主题。

## 下载与更新

- `*-setup.exe`：Windows x64 安装包。
- `*_portable.exe`：Windows x64 绿色版，需要系统具备 WebView2 Runtime。
- `latest.json` 与 `*.sig`：在线更新清单及签名。
- `SHA256SUMS.txt`：下载文件校验值。

v1.1.2 及更早版本需手动安装本版，之后可在关于页检查更新。
绿色版通过在线更新安装后转为安装版，原独立 EXE 不会被替换。
安装前请结束录屏、文件传输和终端任务。
